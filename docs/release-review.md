# 发布审查记录

代码提供者已确认以MIT许可发布到公开仓库 `zhuokaihou/fitness-checkin`。本次发布对象是源码，不包含线上服务部署。原私人服务、数据库、Excel和健康报告配置未被修改。

## 已完成的产品范围

中文手机打卡、通用四分化模板、餐食实际描述、动作重量/工作组/各组次数、有氧/恢复/身体指标、可选目标、周均重趋势与导出。一个账户一个部署，命令行首次设置，无默认密码。可选自配OpenAI兼容模型，连接测试、单日/7/14天分析、备注开关、可查看快照与发送/费用确认、结果保存删除。

## 当前限制

- 本机Docker CLI存在，但引擎未运行；没有实际执行容器构建/启动、容器内UID/卷初始化或Caddy证书申请。Compose校验与本机Gunicorn不能等同于容器部署验收。
- 未连接/部署任何自有Ubuntu服务器；服务器步骤按官方文档准备，实际HTTPS/DNS、防火墙、备份切换需部署者验收。
- 未使用真实API密钥或付费模型；兼容请求/响应以本地模拟和官方接口核对，不保证所有「兼容」提供商支持 `max_completion_tokens`。
- 本地Python版本为3.14，代码以3.12+为目标；远程CI使用3.12，执行结果以仓库Actions记录为准。
- 没有独立第三方安全审计。密钥以服务器权限600明文文件保存，管理员/磁盘备份仍需保护。
- 90天模板通过文件编辑，不提供公共多人服务或复杂计划编辑器。JSON导出当前不提供自动导入；完整恢复使用数据库备份。
