# 计划与数据

## 通用模板

`plan.json` 是公开、重新编写的90天模板，不含个人日期、姓名、体重或营养处方。起始日保存在账户配置，默认账户创建当天；体重/营养/步数目标为空，由使用者填写。

部署者可编辑模板中的每一天，保持 `days` 恰好90项：`day`、`week`、`trainingType`、`actions`、`minutes`、`meals` 等字段。每个动作包含稳定ID、名称、工作组、次数、休息秒数、提示与替换说明。当前没有拖拽计划编辑器。修改后重启应用；Docker需重建镜像。不要修改已记录动作的ID，否则旧动作记录将不能在当前模板对应展示（JSON仍保留）；调整已有部署前先备份。

本地Docker开发可绑定 `plan.json` 只读挂载以方便修改，但不要把个人计划或描述提交公共仓库。Excel下载由当前模板与账户起始日动态生成，不捆绑私人工作簿。

四分化是示例安排，不保证适合所有经验水平。一般活动知识可参考 [WHO 身体活动说明](https://www.who.int/news-room/fact-sheets/detail/physical-activity)；项目不会据此自动生成个人医疗或减重处方。

## 记录语义

| 字段 | 语义 |
| --- | --- |
| `breakfast/lunch/dinner/snack` | 用户打卡状态；完成不证明摄入了任何计划食物 |
| `mealsActual` | 用户填写的实际食物及份量文本，非食物数据库或称量自动读取 |
| `actions[id].weight/sets/reps/done` | 每个动作实际重量kg、工作组数、各组次数文本、完成状态；各项缺失仍为缺失 |
| `workout` | 用户记录的整体训练状态；点完成不会自动填重量、组数或完成每个动作 |
| `cardioMinutes/cardioDistance` | 实际有氧分钟与公里 |
| `weight/waist/steps/sleep/fatigue/notes` | 手动录入的晨重kg、腰围cm、步数、睡眠小时、恢复状态及备注 |
| `revision/updated` | 保存版本与服务器时间；版本不一致时返回409避免覆盖其他页面 |

无数据用空值或缺失字段，界面显示「— / 未记录」。模型摘要显式标注未记录。没有自动健康平台连接；「实际记录」只代表用户输入，不能把它当作经独立校验的医学实测。

周均重只用填写过的晨重；较上周变化仅在相邻周各至少三条晨重时显示。曲线为已有观测，缺失周没有点。目标曲线只是用户目标的线性参考，不代表预测或安全减重速度。

模型分析保存原始文本和对应私有快照，不执行它的指令。估算营养需有足够实际食物/份量，并标明假设与范围；不能从餐食完成状态推出摄入量。

## 数据导出

JSON包含配置目标、全部日期记录和分析文本，不含API配置、密钥、账户密码哈希或会话。CSV包含全部记录与动作/餐食JSON字段，可能以字符串形式出现；防止表格公式注入时对危险开头添加单引号。Excel是计划模板，不是私人记录备份。

导出属于个人健康资料，只在登录后下载。完整恢复使用数据库备份API，见维护文档。
