# 自配模型 API

目前只支持 **OpenAI 兼容 Chat Completions**：向 `{Base URL}/chat/completions` 发送 JSON，带 `Authorization: Bearer ...`，请求包含 `model`、`messages`、`max_completion_tokens`，响应读取 `choices[0].message.content`。Base URL 只接受根路径或 `/v1`；根路径自动使用 `/v1`。兼容性取决于服务商是否支持这些字段，不自动切换协议或增加其他提供商 SDK。

接口依据 [OpenAI 官方 API 参考](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。使用者填写自己已开通的模型 ID，本项目不预设付费模型，不代购额度。

## 设置与测试

1. 登录 → 设置 → 大模型 API，填写提供商名称、Base URL、模型和自己的密钥。
2. 默认允许 `api.openai.com`。其他服务需要部署者在 `LLM_ALLOWED_HOSTS` 中加入精确主机名，如 `api.provider.example`（假值），重启服务。只允许443端口公网HTTPS，不支持浏览器打开内网访问权限。
3. 保存后不回显完整密钥，只有「已配置」状态；同一API地址更新时留空保留旧密钥；更换地址须重新填写对应密钥，避免旧凭据误发给另一服务。删除会清除服务器配置。
4. 「测试连接」先确认费用，发送一条不含健康记录的短消息。测试也可能付费；自动化测试仅调用本地模拟服务。

配置文件为数据目录中的 `llm-config.json`，权限600；数据目录与 SQLite 文件通过私有 umask 创建。密钥不进入前端状态、记录导出、分析提示或日志。文件为明文服务端凭据，磁盘管理员可读取，需保护数据目录并使用加密磁盘/备份；这不是面向共享主机的不可信租户隔离方案。

## 分析流程与发送范围

模型复盘 → 选日期、单日/最近7天/最近14天 → 选择是否包含备注（默认关闭）→ 查看完整 JSON 摘要 → 勾选确认服务商、数据范围和费用 → 发送。

摘要包含选定日期范围、用户手动记录的餐食状态与实际描述、动作重量/工作组/各组次数/完成状态、有氧/步数/睡眠/疲劳/晨重/腰围、自定目标及对应训练计划。没有用户名、密码、API密钥或完整历史；备注默认不发送。描述里主动写入的身份信息会随描述发送，确认前应检查。摘要有效5分钟，绑定当前会话，单次消费；配置变化后旧摘要失效。确认后发送的是刚刚预览的快照，即使另一页面随后更新了记录。

已保存分析展示日期范围、模型、生成时间和文本，可以删除；记录JSON导出包含分析文本。分析依据的快照保存在私人数据库中以供追溯，不作为公开演示。重新分析是新的模型请求，可能再次收费。

## 限制与故障

- 每次外部调用至少间隔30秒，每24小时最多20次，含连接测试及失败调用；跨工作进程共用SQLite限额。
- 每次最多14天数据，备注每条2000字、每餐500字，模型输出限制1800个 completion tokens、128KB响应体。
- 网络连接/读写超时25秒，并检查响应读取总时限；操作系统DNS解析时长仍受系统解析器控制。HTTP错误、无效响应与超时提示安全错误，不保存失败分析。
- 不自动重试，防止超时后重复扣费。失败后重新预览再确认；提供商可能已计费，以其账单为准。
- 不跟随重定向，不使用环境代理；公网DNS结果全部检查，连接固定到已校验IP，HTTPS证书与SNI仍校验原主机。禁止内网、回环、链路本地和元数据地址。
- 本地测试专用 `LLM_TEST_ENDPOINT` 仅支持精确 `http://127.0.0.1:端口/v1`，未放入任何部署模板。生产不要设置；它是测试设施，不是内网API通用开关。
- 模型没有工具调用、文件/终端执行功能。备注与模型输出均视为不可信文本，显示时转义，不解析成HTML。

API不可用不会阻断打卡、趋势或导出。接口不提供后台定时分析，不暗中发送健康数据。
